# iPad 前端审查：导航外壳与真实数据密度（2026-09-11）

> **2026-09-27 账号清理更新：** 当前环境账号和 seed 命令以[环境账号清单](../qa/TEST_ACCOUNTS.md)为准。下文旧账号、演示店及旧密码仅适用于历史记录或隔离测试 fixture，不能作为现行 local/staging/prod 登录配置；原 `ops` 管理员保留。


范围：`apps/web`（前台工作台，门店以「添加到主屏幕」方式在 iPad 上使用）。
不涉及 geniefront-v2，未修改后端、数据库或业务契约，未部署。

本次审查接真库、用真会话（`mia@maildrop.cc`，前台角色）跑完 15 条前台路由 ×
三种 iPad 视口，补上 `2026-09-11-ipad-readability-navigation.md` 结尾留下的那条

## 一、iPad 打开的其实不是前台（三处行为缺陷）

| 问题 | 原因 | 修复 |
|---|---|---|
| 常驻导航在所有 iPad 上都不存在 | 侧栏断点 1280px，而 iPad 横屏只有 1024–1194px，全部落进手机分支 | 侧栏下界降至 1024px；1024–1279px 默认呈 64px 图标轨，可展开为 240px（`Layout.tsx` `SIDEBAR_QUERY` / `RAIL_QUERY`） |
| 店长兼技师在 iPad 上打不开前台工作台 | `isMobileClient` 把 `display-mode: standalone` 当手机信号，而 iPad 添加到主屏幕后该值恒为真，双角色用户被强制路由到技师端 | 判定改为屏幕较短边 < 600px；手机横竖屏都在正确一侧，iPad 不再误判（`lib/session.tsx`） |
| 主屏幕图标冷启动落进技师今日页；方向被锁竖屏 | manifest `start_url: /tech/today`、`orientation: portrait-primary` | `start_url` 改为 `/` 交由路由按角色判定；移除 `orientation`（前台 iPad 常年横屏） |

> 侧栏断点是对 `2026-09-10-ipad-frontend.md` 的有意调整，不是回退。当时移到
> 1280px 是因为**展开态**侧栏在 1024px 下挤压内容；现在回到 1024px 的是
> **图标轨**，占 64px，原先的顾虑不成立。

配套：门店名此前只写在展开态侧栏顶部，图标轨与抽屉形态下无处可读。现补进顶栏，
有切店权限时就地切店 —— 多店运营者在 iPad 上首次能从常驻位置确认当前门店。

## 二、平板字号刻度撞上真实数据（五处裁切）

上一轮把 600–1400px 的字号整体抬了一档，但版式里大量「不可收缩元素 + 单个可
收缩元素」的组合在真实数据下被压垮：

| 页面 | 现象 | 修复 |
|---|---|---|
| 看板 | 列头计数徽章被挤出列外、只露一半 | 标题组补 `min-w-0 flex-1`，徽章 `shrink-0` |
| 看板 | 「超时等候」「待签署」被压成逐字竖排 | 告警行改 `flex-wrap`，各徽章 `shrink-0 whitespace-nowrap` |
| 看板 | 姓名截成「Da…」、号码折三行或截成「(917) 555-01…」 | 列宽由五等分改为 `minmax(15.5rem,1fr)` + 横向滚动；电话独占整幅卡宽的下一行 |
| 日程 | **每一张预约卡都在裁切**（30 分钟单净高 56px，三行内容需 76–97px） | 疏密改为同时看卡片净高：≥88px 显示技师与项目行，≥68px 单列显示时间，更矮则时间并入姓名行 |
| 日程 | 时间轴首个刻度被 sticky 表头切掉上半截 | 首行刻度改 `top-0` |
| 日程 | 日期选择器 44px 热区被父容器 `overflow-hidden` 切掉 13px | 父容器补 `min-h-11` |
| 收银 | 四个状态标签全被截成「已完…」「服务中…」，彼此无法区分 | 1280px 以下改 2×2 排布 |
| 房态 | 「足疗美甲位」压成「足…」 | 副行去掉整行 `whitespace-nowrap`，改为允许换行 |
| 全站 | 勾选框 / 单选框 16×16，触屏几乎点不中 | 触控分支下抬到 24×24（方框本身不能抬到 44px，否则破坏行内版式） |

## 三、非 iPad 专属、本次只记录不改

- **房态筛选栏出现 `pedi_chair`**：自定义资源类型的兜底标签直接落到数据库枚举
  键。已改为回落到后端解析过的多语言显示名。
- **工单项目名显示为 `basic_mani · 0m`**：种子数据的 `ticket_items.name_snapshot`
  是 slug 且 `duration_min = 0`，真实开单路径写的是服务名。属种子数据问题。
- **`ticket_items.name_snapshot` 冻结为开单者当时的语言**（`handlers/ticket.ts`
  写入 `pickText(svc.name, ctx.locale)`）。英文界面的用户回看中文前台开的单会
  看到中文项目名。若「冻结成交时的叫法」不是刻意设计，应改存整段 jsonb 并在
  读取侧 `pickText`，与 `queries/orders.ts:217` 的做法一致。
- **原始权限键与字段名外露给前台**：无权限页写着 `settings.manage`，客户档案的
  健康禁忌横幅写着 `skinAllergies：penicillin`。健康禁忌是安全相关信息，尤其
  不该以字段名呈现。
- **轮牌页文案仍以拖拽为主**（「抓取卡片上下拖动调整顺位」）。HTML5 拖拽在触屏
  上不触发，实际可用的是左侧上下箭头 —— 看板已按这个原则改过文案，轮牌未改。
