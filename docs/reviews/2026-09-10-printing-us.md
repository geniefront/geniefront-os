# 美国门店打印审查与修复

范围：现有 GenieFront OS Web 前台及相关 API；支持在 iPad 浏览器和电脑浏览器中打印。普通纸采用 US Letter（8.5×11 in），小票采用 80mm（约 3⅛ in）内容版式。没有修改 v2，没有部署或运行数据库迁移、重置、种子操作。

## 发现与修复

| 问题 | 修复 |
|---|---|
| 小票、日结、小费签收、二维码、健康表等按钮直接打印整个后台 | 统一独立打印预览。打印内容放在 body 下的独立节点，隐藏其余应用和弹窗，移除滚动高度与操作按钮 |
| 弹窗只打印可见区域，长表可能裁切 | 取消打印内容的 max-height / overflow 限制；表头跨页重复；允许长表分页，行尽量不拆页 |
| 服务单使用 A4，美国纸张不匹配；响应式规则还会影响纸上布局 | 默认 Letter，屏幕断点限定在 screen；预览支持 Letter / 80mm 切换 |
| 结账按钮称会打印，但实际没有收据链路 | 收银页和看板收银成功后按门店 autoPrintReceipt 设置打开独立收据页；关闭设置时收银页保留最近收据入口，订单历史可补打 |
| 设置声称自动控制网络热敏打印机 | 文案改为结账后打开收据，再选择打印机；不声称静默打印、切纸或已经送达纸张 |
| 收据和日报使用写死的店名 | 打印收据从服务端读取真实门店名称、地址、电话与页脚，兼容旧地址 JSON；日报使用当前门店名称 |
| 一张服务分配多名技师后，历史订单明细因 SQL join 出现重复收费行 | 按 item ID 合并技师展示；每个项目只保留一笔金额；优先保留售出时的项目名称快照 |
| 小票依赖当前页数据，可能找不到较早订单 | 新增 `/v1/desk/tickets/:ticketId/receipt`，按 UUID 精确查询，检查读取权限并通过 withTenant 隔离门店 |
| 金额口径与隐私 | 顾客收据使用实际服务明细、USD、税、小费、折扣、退款、付款渠道；预付套餐抵扣单列；现金显示递交金额与找零；不印内部小费分配与审计备注 |
| 美国时间显示依赖设备时区 | 顾客收据使用 en-US 格式和门店时区；健康存证也标明门店时区 |
| 健康存证打印没有单独记录导出访问 | 明确使用 export 原因读取，打印预览前重新获取并留痕；服务单同样重新读取；无联系方式权限时服务单不返回手机号 |
| 敏感打印数据自动落入通用离线缓存 | 收据和服务单接口返回 Cache-Control: no-store；前端遵守该标记。通用缓存读写键同时纳入实际门店身份 |
| 签名图片未加载时打印、取消后假报成功 | 图片和字体准备完成才启用打印；图片失败时阻止打印；afterprint 不视为成功、不自动关页，允许取消后重印 |
| 二维码纸上缺少标题或出现空输入框 | 保留矢量二维码和静区，添加纸上标题，隐藏复制链接控件 |
| 对账打印夹带导出弹窗或只印视口内容 | 独立数据表打印，明确标题中的已加载记录数量，不把当前加载范围声称为完整历史账目 |

## 使用

1. 普通打印机：打开打印预览，选 US Letter，在系统对话框选择 Letter 纸张。建议关闭浏览器页眉页脚（网址、日期），按实际大小打印。
2. 80mm 小票机：选择 Receipt (80 mm)，在驱动/系统对话框选择匹配的 80mm 纸卷。内容区 74mm，两边预留约 3mm。纸卷长度、切纸和设备可打印边距由驱动控制；应用不强制虚构的固定纸卷长度。
3. iPad：需要支持 AirPrint 的打印机，并与 iPad 位于可互相发现的同一 Wi-Fi 网络。热敏小票机也需满足此条件；仅有 USB、蓝牙或普通网口不等于支持 AirPrint。参见 [Apple AirPrint 说明](https://support.apple.com/en-us/109349)。
4. 电脑：使用操作系统已安装的打印机驱动，也可保存 PDF。Letter 页面规则参见 [MDN @page size](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/%40page/size)。
5. 收据加载失败时使用“Retry receipt”；这只重读收据，不重试收款。打印取消不会触发再次收款。

- Web 全量回归：369 项通过；随后新增的预付抵扣/现金找零测试以及打印模块共 5 项通过。

- Chromium 与 WebKit：实际应用收据页、Letter/80mm 切换、取消/重印、关闭预览、120 行报表、HeroUI 二维码弹窗转打印预览均通过。
- PDF：Letter 页面尺寸为 612×792 pt；80mm 样张宽 227.04 pt；120 行报表分页为 5 页，最后一行存在；未打印工具栏或返回按钮。已渲染检查收据、报表各页及二维码。
- 合成样张与截图：`artifacts/print-review/`，全部标记 SAMPLE，非真实客户资料。

## 实测边界

没有连接实体打印机，尚未验证具体机型的 AirPrint 发现、实际出纸、切纸与走纸长度。WebKit 是浏览器兼容性验证，不代替真实 iPad。当前订单页 API 仍有分页，财务对账打印覆盖页面已加载/筛选的记录并标明数量，不是跨全部历史数据的财务导出。没有新增 ESC/POS、USB/Bluetooth 直连代理或无人值守打印服务。构建保留既有大体积分包警告。
