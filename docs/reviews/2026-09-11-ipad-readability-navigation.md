# iPad 前端审查：阅读字号与返回路径（2026-09-11）

范围：`apps/web`（前台工作台，门店以「添加到主屏幕」方式在 iPad 上使用）
与 `apps/ipad`（顾客自助机）。不涉及 geniefront-v2。

## 一、字号太小

字号刻度只在 600–1400px 视口内整体抬一档，间距、圆角、控件尺寸继续用 rem
且不随之改变 —— 放大的是字，不是布局，因此版式关系保持原样。

| token | 原 | 现 |
| --- | --- | --- |
| `text-xs` | 14px | 15px |
| `text-sm` | 16px | 17px |
| `text-base` | 16px | 18px |
| `text-lg` | 18px | 20px |
| `text-xl` | 20px | 22px |

配套处理：

- 代码里写死的 748 处 `text-[9px]`–`text-[13px]` 统一抬到与 `text-xs` 同级。
- 输入控件跟随同一刻度。原先触控分支里的 `max(1rem, 16px)` 是为手机防止 iOS
  聚焦放大页面设的下限，在平板上反而比正文小，现由平板分支覆盖。
- 徽章、状态标签一类用固定高度（`h-5`/`h-6`/`h-7`）掐死的容器改为最小高度，
  避免字号抬高后把字母上下缘切掉。
- 自助机同步抬档（顾客站着、手臂长度之外读）。

## 二、打印完退不回看板

原因是站内地址用 `window.open(..., '_blank')` 打开。独立窗口不支持标签页，
iOS 会把地址交给 Safari 另起上下文，该上下文没有可回退的历史记录，返回手势
直接退出应用。同类问题还有 `window.close()`（非脚本打开的窗口关不掉）。

`apps/web/src/lib/navigation.ts` 定下两条规则并提供实现：

- `useOpenInternalRoute()` —— 独立窗口下压入当前历史栈，浏览器环境下保留开新
  标签页的习惯（前台电脑要摊开多张单子对照），弹窗被拦截时退回站内跳转。
  已接入：看板打印服务单、预约抽屉查看健康表单、到店签到查看已签问卷。
- `useGoBack(fallback)` —— 脱离主布局的整页自带返回控件；没有站内历史可退时
  落到兜底路由而不是退出应用。已接入：服务单打印页（新增返回按钮）、小票打印
  页、健康表单存证页（替换掉 `window.close()`）。
