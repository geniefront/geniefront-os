- 财务样例是历史阶段记录。已退钱／已终止的样例不重复运行其早期付款或核销 verifier；新的演练另建业务键。保留库 `gf_commerce_ci` 不 reset，已应用 SQL 不改写。
- 管理员配置、销售、核销、退款、日结、功能开关和回滚见 [运维说明](../ops/customer-commerce.md)。门店会员新销售开关仍保留测试前状态；有权限的店家可按说明开启。

QA 通知使用 capture；现金是前台测试记录。未拨打实体电话、给真实顾客发信、进行 live 扣款或生产发布。AI 电话预约的签名工具入口、待付款说明、测试支付和前台处理已有证据；生产 agent 发布属于后续上线操作。
